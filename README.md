# 🍪 Cookie Clicker (C# WinForms)

Můj první ucelený projekt v jazyce C# a frameworku Windows Forms. Jedná se o klon populární oddechové hry, který tvořím v rámci rozšiřování svého portfolia a učení se novým věcem.

## 🎮 Funkce hry
* **Hlavní mechanika:** Získávání bodů (sušenek) pomocí klikání na interaktivní obrázek.
* **Obchod a vylepšení:** Systém nákupů, kde si hráč může za nasbírané sušenky koupit silnější klik.
* **Pasivní příjem:** Automatické generování sušenek v čase pomocí komponenty `Timer`.
* **Vlastní UI:** Postupný přechod od základních Windows tlačítek k vlastnímu grafickému rozhraní.

## 🛠️ Použité technologie
* **Jazyk:** C#
* **Framework:** Windows Forms (.NET)
* **Vývojové prostředí:** Visual Studio 2026

## 🚀 Jak hru spustit
1. Stáhni si tento repozitář (zelené tlačítko *Code* -> *Download ZIP*).
2. Otevři soubor řešení (`.sln`) ve Visual Studiu.
3. Stiskni `F5` nebo klikni na tlačítko Start (Debug) pro zapnutí hry.
